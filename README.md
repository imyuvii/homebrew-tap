# imyuvii's Homebrew tap

```bash
brew tap imyuvii/tap
brew trust --cask imyuvii/tap/dev-pilot-board   # Homebrew 7+ requires trusting third-party casks
brew install --cask dev-pilot-board
```

| Cask | Description |
|---|---|
| [`dev-pilot-board`](https://github.com/imyuvii/dev-pilot-board) | Menu-bar status board for Claude Code and GitHub Copilot CLI sessions |
